# Agentic AI

Welcome to the **Agentic AI** project!

This repository is created to explore the basic concepts of **Agentic Artificial Intelligence** and understand how AI agents can perform tasks, make decisions, and interact with tools.

## About the Project

Agentic AI refers to AI systems that can work toward a goal by planning actions, making decisions, and using available tools.

This repository will contain simple examples and learning resources related to Agentic AI.

## Topics

- Artificial Intelligence
- Generative AI
- Large Language Models (LLMs)

- Prompt Engineering
- Tool Usage
- Agentic Workflows
